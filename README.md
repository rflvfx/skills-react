## 📋 Sobre

Biblioteca de padrões React: componentes reutilizáveis, hooks customizados e gerenciamento de estado com context.

## 📂 Conteúdo

- `src/components/Button.jsx` — componente com variantes
- `src/hooks/useFetch.js` — fetch com loading/error
- `src/hooks/useLocalStorage.js` — estado persistido
- `src/context/ThemeContext.jsx` — tema light/dark
- `patterns.md` — padrões de composição
- `index.html` / `src/` — app de exemplo

## 🚀 Quick start

```bash
npm install
npm run dev
```
